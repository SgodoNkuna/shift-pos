# Shift POS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free, installable phone app (PWA) that replaces the paper shift sheet. It covers till sales, stock in/out with live approval, expenses, the joint handover count, and a locked PDF + XLSX report shared to WhatsApp.

**Architecture:**
- All shift logic lives in pure TypeScript functions (`src/domain`) with no I/O, tested first against the real sheet numbers.
- The UI writes every action to IndexedDB first. An outbox syncs it to Supabase (Postgres + RLS + Realtime).
- Reports are made on the phone. Push notifications and timed reminders run in Supabase (Edge Functions + pg_cron).
- Cloudflare Pages hosts the static app.

**Tech Stack:** Node 22, Vite 8, React 18, TypeScript, Tailwind 4, Vitest 5, Dexie 4 (IndexedDB), jsPDF 4, ExcelJS 4, @supabase/supabase-js 2, vite-plugin-pwa 2, Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-11-23-shift-pos-design.md` · Prototype: `prototype/shift-pos-walkthrough.html` (screens and copy to match)

## Global Constraints
- Running cost R0. Free tiers only: Supabase Free and Cloudflare Pages Free. No Vercel Hobby (non-commercial only). No paid SMS or WhatsApp API.
- Money is stored as integer **cents**. Quantities are numbers rounded to **0.1** with `roundQty`. Step is **1** for `ea` and **0.5** for `g`.
- Currency ZAR, shown as `R1,180`. Timezone `Africa/Johannesburg`. Shifts: **day 08:00–20:00**, **night 20:00–08:00**. A shift's `date` is the date it **starts**.
- Roles: `employee` | `manager` | `boss`. The permissions table in spec §6 is the source of truth and is enforced in RLS, not only in the UI.
- Cost prices are never sent to non-boss users. Use a separate table with boss-only RLS.
- Stock-out escalation to managers after **5 min**. Report reminder to the sender at **15 min**, and boss + manager alert at **30 min** (boss-editable).
- A one-item cash sale takes **≤3 taps**. Look: dark "vault" (tokens from the prototype `:root`). Copy: plain English, grade 5–7 reading level.
- Every total is derived from its lines. No UI field may type a total.

## Review Focus
1. **Offline then back online:** a sale made offline syncs exactly once even if the send is retried. The ID is made on the phone, and the server uses upsert on `id`.
2. **Price changed mid-shift:** earlier sales keep their `unitCents`. Report sales use line prices, while stock value uses the current price.
3. **Gram arithmetic:** 0.5 + 0.5 + 0.5 − 1.5 must equal exactly 0, not `1e-16`.
4. **Count typed oddly:** `"1,5"`, `" 3 "`, `"R350"`, empty. Parse to a number or "not entered", never `NaN`.
5. **Night shift past midnight:** a sale at 02:00 on 29 Nov belongs to the night shift dated 28 Nov.

### Task 3: Shift calculations

**Files:**
- Create: `app/src/domain/calc.ts`
- Test: `app/src/domain/calc.test.ts`
- Create: `app/src/domain/fixtures.ts` (sheet products and scenarios)

**Interfaces (Produces):**
- `itemLines(d: ShiftData): ItemLine[]`, where `ItemLine {productId; open; stockIn; out; pendingOut; sold; expected; counted: number|null; diff: number|null; diffCents: number|null; salesCents; stockValueCents}`
  - `expected = open + stockIn − approvedOut − pendingOut − sold`
  - `counted` = `shift.counts[id]` or null; `diff = counted − expected`
  - `stockValueCents = (counted ?? expected) × current price`
  - Voided sales are excluded everywhere.
- `shiftTotals(d): {salesCents; cardCents; cashCents; expensesCents; expectedCashCents; cashDiffCents: number|null; cardDiffCents: number|null; categorySalesCents: Record<string,number>}`
- `changeDue(totalCents, tenderedCents): number`
- `shiftFlags(d): Flag[]`, where `Flag {level: 'bad'|'warn'|'ok'|'info'; code: 'stock_diff'|'cash_diff'|'card_diff'|'cash_ok'|'card_ok'|'stock_out'|'low_stock'|'category_mismatch'|'category_ok'|'void'; text: string; productId?}`
- `canLock(d): {ok: boolean; reasons: ('pending_out'|'no_cash_count'|'no_card_slip'|'missing_pin_out'|'missing_pin_in')[]}`
